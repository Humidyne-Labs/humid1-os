# Audio Clip Samples  
This dir contains a public directory for the audio that will be featured on the Humid1_OS.

### Note:  
So, I'm pretty sure I have the audio samples worked out. 
I may add a few more states eventually, but this is a good starting point.  

`sample.audio_manifest.json` is a template for future use.
