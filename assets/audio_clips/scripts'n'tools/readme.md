# Scripts'n'Tools Dir

- `gen/samples/eval_voice.py` is a script for playing the collection of audio samples, generated by `test_all_free_voices.py`, for personal review.  
- `gen_samples/line_to_mp3_tracked.py` is a script for generating audio samples, `gcloud auth login` was used for authentication, no API key needed.  
- `gen_samples/test_all_free_voices.py` is a script for generating a  collection of sample audio, used for review.  
- `docs/8-2026__SKU_API_Tier_Limits.pdf` this doc is what I used as a reference for tracking API usage. Google won't allow me to set a usage cap for some unknown reason.  
- `utility/audio2pcm.py` is a script for comverting audio files to pcm/bin/.h files.
- `utility/play_audio_header.py` is a scrip for testing and debugging the audio files and conversion pipe-line.
